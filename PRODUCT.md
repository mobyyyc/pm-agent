# Product

## Register

product

## Users

Project owners, product managers, and small technical teams use VERSOR PM Agent while turning rough ideas into structured execution. They need a calm operating surface for projects, tasks, timelines, GitHub context, members, progress reports, and PM agent proposals.

## Product Purpose

VERSOR PM Agent converts plain-language project intent into useful project operations: guidelines, timelines, tasks, team ownership, repository signal, activity review, progress reports, and approval-gated PM agent actions.

## Brand Personality

Calm, structured, professional. The app should feel like reliable project software with AI assistance built in, not an AI demo wrapped around project data.

## Anti-references

Avoid flashy AI dashboard styling, crypto dashboard styling, gaming UI, neon gradients, harsh black blocks in light mode, oversized controls, inconsistent one-off page treatments, low-contrast accent text, and aesthetics that reduce readability.

## Design Principles

1. Make AI operational, not theatrical.
2. Use consistency as an affordance across every page, panel, warning, button, badge, and control.
3. Keep project status and next actions easy to scan before details.
4. Preserve user control, especially for agent proposals and approvals.
5. Keep the current clean SaaS identity, then refine hierarchy, rhythm, and contrast.

## Accessibility & Inclusion

Target readable WCAG AA contrast in light and dark mode. Keep controls keyboard focusable, preserve visible focus states, avoid color-only state communication, and keep mobile touch targets comfortable.
